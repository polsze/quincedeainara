
# Quince de Ainara — Interactive Event Website

Custom event website developed for **Ainara's 15th Birthday Celebration**, combining a personalized digital invitation with interactive features for guests.

🌐 **Live Website:** https://quincedeainara.blog/

## 📌 About the Project

A personalized event platform designed to provide guests with an engaging digital experience, combining event information, visual content, and interactive functionality.

One of its key features allows guests to submit music suggestions for the celebration, with submissions stored in a Supabase database.

## 🚀 Main Features

- Custom visual design tailored to the event.
- Responsive interface for desktop and mobile devices.
- Interactive digital invitation and event information.
- Guest music suggestion submission system.
- Supabase database integration for storing music requests.
- Dynamic data handling and user interaction.
- Dedicated sections for event details.
